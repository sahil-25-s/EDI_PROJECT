FREQUENTLY ASKED QUESTIONS

How do I start solving problems?
Go to Practice Mode from your dashboard, select a topic or difficulty level, and start coding! Each problem includes a detailed description and example test cases.
What programming languages are supported?
Currently we support C++, Java, Python, and JavaScript. You can switch between languages in the code editor.
How does the XP and leveling system work?
You earn XP by solving problems and completing lessons. Every 100 XP increases your level. Higher difficulty problems give more XP.
Can I compete with other users?
Yes! Use Battle Mode to compete in real-time coding challenges. Your battle rating increases with wins and affects your leaderboard position.
Is CODECADE free to use?
Yes, CODECADE is completely free! All features including practice problems, battles, and learning modules are available at no cost.
