Efficient solution for Two Sum problem

Here's an O(n) solution using HashMap. The key insight is to store complements as we iterate through the array...

def twoSum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
